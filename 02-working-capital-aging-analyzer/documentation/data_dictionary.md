# Data Dictionary

| Table | Purpose |
|---|---|
| `customers` | Customer master, segments, credit limits, and terms |
| `vendors` | Vendor master, categories, and payment terms |
| `sales_invoices` | Customer billing transactions |
| `customer_payments` | Full or partial receipts against invoices |
| `purchase_bills` | Supplier obligations |
| `supplier_payments` | Payments against supplier bills |
| `inventory_snapshots` | Period-end inventory balance |
| `monthly_financials` | Credit sales and COGS denominators |
| `ar_aging` | Open receivables with aging buckets |
| `customer_risk` | Customer risk score and cash-release opportunity |
